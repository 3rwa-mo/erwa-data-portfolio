# Erwa Mohamed — Data Analyst Portfolio

A responsive personal portfolio for Erwa Mohamed, an aspiring data analyst. The site introduces Erwa's learning journey, current toolkit, project ideas, and contact links.

## Features

- Responsive layout for desktop and mobile
- Soft glass-inspired interface
- About, skills, project, and contact sections
- Project cards ready to update with study work
- Custom `E` favicon

## Built with

- HTML5
- CSS3
- Font Awesome icons
- Google Fonts (DM Sans and Manrope)

## Run locally

No build step is required. Open `index.html` in a browser, or serve the folder with any static web server.

## Customize

- Update the LinkedIn and GitHub URLs in `index.html` to point to your profiles.
- Replace the project ideas with completed projects as you progress through your studies.
- Update the skills and learning status to reflect your current experience.
- Replace `images/hero-headshot.jpeg` if you want to use a different profile photo.
